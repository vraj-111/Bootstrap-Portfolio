# Vraj's Portfolio

A premium, futuristic personal portfolio website for **Vraj Desai**, a Full-Stack Web Developer from Bhavnagar, Gujarat, India.

## Features

- **Dark/Light Theme** - Toggle between themes with localStorage persistence
- **Responsive Design** - Works on all screen sizes (320px to 1440px+)
- **Glassmorphism UI** - Modern glass-effect components
- **Typing Animation** - Animated role text in hero section
- **Particle Effects** - Canvas-based particle background
- **Mouse Glow** - Subtle cursor-following glow effect (desktop only)
- **Custom Cursor** - Animated cursor dot and ring (desktop only)
- **Scroll Reveal** - Elements animate when entering viewport
- **Active Navigation** - Highlights current section in navbar
- **Smooth Scrolling** - Smooth anchor link navigation
- **Loading Screen** - Premium loading animation
- **Copy Email** - One-click email copy with toast notification
- **Contact Form** - Form validation with mailto fallback
- **Back to Top** - Scroll-to-top button
- **Accessibility** - Semantic HTML, keyboard nav, ARIA labels, prefers-reduced-motion support

## Tech Stack

- HTML5 (Semantic)
- CSS3 (Variables, Flexbox, Grid, Animations, backdrop-filter)
- Vanilla JavaScript (No dependencies)
